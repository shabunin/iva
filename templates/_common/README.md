# {{name}}

A CommandFusion iViewer panel, written in JSX and built with
[iva](https://github.com/shabunin/iva).

```bash
iva dev      # live preview
iva check    # check before building
iva build    # dist/{{slug}}.gui (+ assets/: images, scripts/) for iViewer / GUI Designer
iva serve    # to iViewer on a device: GUI File URL http://<this machine>:8019
```

Elements and props: `IVA.md`. The iva/ui components: `IVA-UI.md`. Web apps: `IVA-WEB.md`. Drivers (MQTT ...): `IVA-DRIVERS.md`. Notes for AI assistants: `AGENTS.md`.
