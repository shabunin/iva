iva panel

A .gui or a zipped GUI on a web server (http://, cf://), or iva serve's address; ?page=Name the page to start on. This is the panel's default GUI: what it starts with, where CF.loadGUI(null) goes. Demo: the iva/ui gallery, built into the app - no server needed.

Copies on this device

A GUI loaded from its server is kept here and starts without the server next time (the server is asked for a newer one behind it). Per GUI: whether a copy is kept, one saved now, one cleared.

Settings again: three fingers on the screen, Ctrl+S or F1 on a keyboard, or a finger held in the top-left corner. Ctrl+R: the GUI again from its server.
